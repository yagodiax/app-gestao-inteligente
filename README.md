# Gestão Inteligente

Sistema desktop de gerenciamento administrativo e financeiro, desenvolvido em **Pascal** como parte do Trabalho de Conclusão de Curso (TCC) do curso Técnico em Informática do SEICE, em 2024.

O projeto Gestão Inteligente surgiu com a proposta de apoiar pequenas lojas de roupas que não possuíam recursos tecnológicos para divulgação online, oferecendo soluções de presença digital e divulgação comercial.

Este repositório contém o aplicativo desktop desenvolvido para auxiliar no controle administrativo e financeiro da empresa.

## Sobre o projeto

A Gestão Inteligente foi idealizada como uma empresa voltada à transformação digital de pequenos negócios, especialmente lojas de roupas.

A proposta empresarial contemplava uma plataforma online centralizada para divulgação de lojas, apresentação de produtos e possibilidade de criação de páginas individuais para os estabelecimentos.

Como parte dessa estrutura, foi desenvolvido um aplicativo desktop destinado ao gerenciamento interno das operações financeiras e administrativas da empresa.

## Funcionalidades

O aplicativo desktop conta com os seguintes recursos:

- **Controle de vendas:** registro, consulta e gerenciamento de vendas realizadas.
- **Controle de despesas:** lançamento e acompanhamento dos gastos da empresa.
- **Gerenciamento de serviços:** cadastro e administração dos serviços oferecidos e seus respectivos valores.
- **Gerenciamento de usuários:** cadastro, edição e controle de acesso dos usuários.
- **Relatórios de vendas:** consulta de vendas por período e serviço.
- **Resumo financeiro:** acompanhamento dos valores de vendas, despesas e resultados financeiros por período.
- **Autenticação:** acesso ao sistema por meio de usuário e senha, com controle de perfil.

## Tecnologias utilizadas

- **Pascal:** linguagem de programação utilizada no desenvolvimento.
- **Lazarus / Free Pascal:** ambiente e ferramentas de desenvolvimento.
- **MySQL:** sistema de gerenciamento de banco de dados.

## Estrutura do banco de dados

O banco de dados do aplicativo possui quatro entidades principais:

| Tabela | Descrição |
|---|---|
| `admin` | Armazena os usuários e suas informações de acesso. |
| `vendas` | Registra as vendas realizadas. |
| `gastos` | Armazena as despesas da empresa. |
| `servicos` | Armazena os serviços oferecidos e seus valores. |
